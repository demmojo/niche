## Learned Workspace Facts

Archival strictly requires `learnings_extracted: true`. For AI-native specs, frame validations as manual end-to-end simulations. Use `npm run openspec <command>`.
- **OpenSpec Execution**: Respect task order, use GraphRAG. Automate 'Halt and Update' for re-validation. When parsing terminals, use `tail`/`grep` to avoid LLM context exhaustion.
- **Frontend & UX**: Handle React 19 'Snapshot Beats the Fetch' race conditions by implementing an `AbortController` hooked to tenant/workspace dependencies (e.g., `workspaceId`) inside fetch hooks. Prevent render cascades by splitting React Contexts (separating state and dispatch) for global providers like `<WorkspaceProvider>`. Avoid hacky external scripts for frontend logic injection. Implement Generative UI for dashboards. Use Explainable States (`aria-live="polite"`) for screen readers instead of generic spinners.
- **Testing Standards**: Mandate RTL+MSW, Firebase Emulators, Playwright. Prove JSON stream parsers mathematically via `fast-check`. Mid-stream `AbortController` cancellations must gracefully degrade without fatal Error Boundaries.
- **React 19 & Streams in Vitest**: When testing components consuming SSE or Promises via `use()` and `<Suspense>`, wrap the initial `render()` and every subsequent stream injection (e.g., `controller.enqueue()`) in `await act(async () => { ... })` to prevent "suspended inside an act scope" errors.
- **Playwright SSE Mocking**: Mock Server-Sent Events in `page.route` by fulfilling the route with a single concatenated string of chunks (`chunks.join('')`) and setting the `Content-Type: text/event-stream` header. The browser handles the decoding natively without requiring complex async generator mocks.
- **Vitest & Firebase**: Global Vitest teardown must terminate `globalThis.firestoreInstance` and delete the Firebase app instance to prevent CI memory leaks.
- **LLM Evaluation (CI/CD)**: Use `stochastic-eval.yml` with `measureVariance` statistical runners for non-deterministic iterations. Use `gemini-3.1-pro` (`evaluatePairwise`) as an automated Pairwise Judge for pre-merge PR gating.
- **LLM Safety & Outputs**: Validate LLM outputs/schema drift with Zod discriminated unions. Prevent prompt injection using regex `replace(/[<>]/g, "")`.
- **LLM Output Overrides**: Never rely solely on LLM semantic output for definitive classification (e.g., Tarpit Validation). Implement a "System Override" pattern that uses deterministic mathematical thresholds (like `orthogonalDistance`) to correct LLM hallucinations or false positives, appending a `[System Override]` flag to the output reasoning.
- **Zod Validation in Tests**: Avoid exact string assertions on Zod error messages, as schema updates will break tests. Instead, assert on the presence of ZodError structures or use discriminated unions to predictably handle validation states.
- **Vitest Mocking & Timers**: When mocking `firebase-admin`, avoid `.default` fallbacks. For dynamic imports (e.g., `@google/genai`), use `async (importOriginal)` to preserve types. When mocking global `fetch`, always include `clone: function() { return this; }` instead of an arrow function to prevent recursive `this` serialization errors during test failures or deep equality checks. Ensure mocked HTTP 202 endpoints resolve correctly with floating promises to prevent timeout issues in Vitest. For browser global fallbacks (e.g., `requestIdleCallback`), use `delete (window as any).prop` instead of `vi.stubGlobal(..., undefined)`. For MSW + fake timers, enforce `vi.runOnlyPendingTimers()` and `vi.useRealTimers()` in `afterEach`. For MSW mocking of HTTP 202 Accepted endpoints against local emulators, handle background work using "floating promises" to prevent test timeouts.
