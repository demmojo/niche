# Rapid PDLC Prompt Exporter

This feature enables users to transition from product strategy to code by exporting optimized prompts and validating external AI-generated code.

## Features

### 1. Strategy-to-Code Wizard

- **Requirement:** A multi-step modal (`StrategyToCodeWizard.tsx`) that guides the user through Configuration, Handoff (Export), and Validation.
- **Requirement:** Step 1 (Configure) allows the user to select the Scope (Whole App vs. Component), Tech Stack (React/Tailwind, Vue, Svelte), and Context Level (Strict Adherence vs. Creative Freedom).
- **Requirement:** Step 2 (Handoff) displays the generated prompt in a syntax-highlighted block. It includes sticky buttons to "Copy to Clipboard" (using modern `navigator.clipboard` with visual feedback) and "Download as .md".
- **Requirement:** Step 3 (Validate) provides a text area where users can paste the code generated by external tools (v0, Bolt) for AI review.

### 2. Client-Side Prompt Assembler

- **Requirement:** A pure TypeScript utility (`src/utils/promptAssembler.ts`) that accepts `MyProductData` and configuration settings, returning a highly structured Markdown string.
- **Requirement:** The generated prompt must use explicit bracketed sections (`[CONTEXT]`, `[OBJECTIVE]`, `[CONSTRAINTS]`, `[RESPONSE]`).
- **Requirement:** The assembler must inject Top JTBDs, Competitor Anti-patterns (Negative Prompts), Target Audience, and explicit Tech Stack instructions into the `[CONSTRAINTS]` and `[CONTEXT]` sections.

### 3. Loop-Back Artifact Reviewer

- **Requirement:** When a user pastes code in Step 3, the system makes an LLM call to evaluate the code against the specific strategic constraints defined in Step 1.
- **Requirement:** The AI response must provide dimension-specific checks (UX, Constraints, Stack) and actionable fixes or a rewrite prompt if validation fails.

### 4. Metadata Storage

- **Requirement:** The system records an export event by appending a `GeneratedPromptMeta` object to `MyProductData.generatedPrompts`.

## Scenarios

- **WHEN** the user clicks "Generate UI Code" on a JTBD or Feature
- **THEN** the `StrategyToCodeWizard` opens at Step 1, pre-filled with the context of the selected item.

- **WHEN** the user selects "React/Tailwind" and clicks "Next"
- **THEN** the system instantly generates the CO-STAR structured prompt client-side and displays it in Step 2 with "Copy" and "Download" buttons.

- **WHEN** the user clicks "Copy"
- **THEN** the prompt is copied to the clipboard, the button briefly changes to "Copied! 🚀", and a metadata record is saved to the user's state.

- **WHEN** the user pastes external code into Step 3 and clicks "Validate"
- **THEN** the system queries the AI Critic model and returns a structured evaluation highlighting any strategic or UX flaws in the pasted code.
