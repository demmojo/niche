# Proposal: ML Orchestration, Model Routing, and Prompt Engineering System\n\n## Why\nCurrently, the NicheAI codebase lacks a unified, dynamic system for selecting Large Language Models (LLMs) based on task specifications. Hardcoding models (such as the deprecated `gemini-3-flash-preview`) creates brittleness, leads to API failures, produces suboptimal performance, and results in wasted tokens. In addition, prompt engineering across the codebase lacks standardization, causing unstructured outputs and potential prompt injection vulnerabilities.\n\n## What Changes\nWe are replacing static model selection with a dynamic, capability-driven smart routing orchestration layer. We are migrating to a persistent datastore for queuing to support true async workloads safely. We are also standardizing all prompt generation using the CO-STAR framework based on Leeropedia best practices, and enforcing structured JSON outputs via native schemas.\n\n## Capabilities\n1. **Capability-Driven Smart Routing:** Semantic routing layer (`Capability`) directing tasks to the appropriate tier (Lite, Fast, Pro) based on complexity, latency, and cost.\n2. **CO-STAR Prompt Standardization:** Enforced implementation of the CO-STAR framework for all prompt assemblies.\n3. **Structured Outputs & AST Sanitization:** Native Zod JSON schemas for extraction, eliminating regex parsing.\n4. **Asynchronous Orchestration & Backward Compatibility:** Enforced HTTP 202 Accepted pattern with a Redis-backed persistent queue (e.g., BullMQ) for heavy ML tasks, alongside a versioned migration path to keep legacy synchronous clients functional.\n\n## Impact\n- **Reduced Cost & Latency:** By pushing lower-complexity extraction to Lite models, token waste is heavily reduced.\n- **Increased Reliability:** Zero regex parsing and Zod-native structure guarantees parseable outputs. Distributed persistent queues prevent memory exhaustion.\n- **Improved UX (PLG Strategy):** Users default to a seamless "Auto" mode, and high-latency Pro tasks expose staggered, explainable loading states.
