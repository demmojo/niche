# Spec\n\n## Detailed Features\n- **The Niche Radar Feed**: A public, live feed displaying recently discovered, un-locked niches to build FOMO.\n- **Market Gap Report Generator**: A massive input field above the fold (`Describe an audience or industry...`) that triggers the Reverse Demo hook.\n- **Teaser View**: A report displaying the Market Name, Total Addressable Market (TAM), Jobs to be Done (JTBD), and a 'Tarpit Score'.\n- **Premium Locked View**: Hidden sections including Exact Competitor Weaknesses, step-by-step GTM Strategy, Long-tail SEO keywords, and the 'First 100 Customers' playbook.\n\n## Scenarios\n\n**Scenario 1: Generating a Public Report**\n- **WHEN** an unauthenticated user enters an industry like 'Plumbers' and clicks generate\n- **THEN** the BFF verifies App Check, uses Gemini Flash-Lite to generate the report, creates a 72-hour TTL ghost session, and displays the report.\n\n**Scenario 2: Viewing the Teaser**\n- **WHEN** the user views the newly generated Market Gap Report\n- **THEN** they see the TAM, JTBD, and Tarpit Score clearly, but the GTM Strategy and SEO Keywords are blurred out with a 'Lock this Market' CTA overlay.\n\n**Scenario 3: Locking the Market (Conversion)**\n- **WHEN** the user clicks 'Lock this Market'\n- **THEN** the system triggers anonymous-to-auth conversion using React 19 `useActionState`, grants ownership of the niche, and reveals the premium unblurred data.\n\n**Scenario 4: Niche Collision**\n- **WHEN** a user searches for a hyper-niche that has already been 'Locked' by another founder\n- **THEN** the system prevents generation and returns a pivot message: 'This market gap has been locked. Here are 3 adjacent, untapped niches...'\n\n**Scenario 5: Viral Sharing**\n- **WHEN** a user clicks share on a public report\n- **THEN** a dynamic OG image (showing Title, TAM, and Tarpit dial) is generated and a pre-filled Twitter/LinkedIn intent opens.
