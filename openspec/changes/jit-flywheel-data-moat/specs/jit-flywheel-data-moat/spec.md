# Specification: JIT Flywheel

## Core Features

### 1. Vector Sync Worker Provenance

Offline data syncing must include `provenance: { source: "batch_baseline" }` to protect organic `demand_score` metrics generated by the JIT flywheel.

### 2. JIT Endpoint (`POST /validate-jit`)

Uses SSE to stream data. It parses input, streams Exa results, triggers Gemini for structural parsing, and dispatches a background Cloud Task via Claim Check.

### 3. Collision Engine Worker (`POST /api/internal/worker/flywheel-cache-jit`)

Background worker that retrieves the payload, stores the raw user query in `founder_demand_queries`, normalizes competitor URLs (stripping `www.`, lowercase, parsed via `URL`), and increments competitor `demand_score` using `WriteBatch`.

### 4. Semantic Gatekeeping & Telemetry

Inputs must pass a fast LLM Intent Classification Check (e.g., `gemini-3.1-flash-lite-preview`). Frontend components (`ZeroFrictionEntry`, `FounderWorkspace`) will provide UI elements like drag-and-drop focus points and explicit AI pivot rejection tracking.

## Scenarios

**Scenario 1: Standard JIT Request**

- **WHEN** a user submits an idea to `/validate-jit`
- **THEN** the server opens an SSE connection, streams Exa search results (<2s), triggers Gemini, streams final structured JSON, and queues a Cloud Task.

**Scenario 2: User Disconnects Early**

- **GIVEN** the JIT endpoint is processing a request
- **WHEN** the user closes the browser tab
- **THEN** the `req.on('close')` event fires, triggering the `AbortController` to halt pending Exa or Gemini network requests.

**Scenario 3: Adversarial Input**

- **WHEN** a user inputs XSS or prompt injection payloads
- **THEN** Zod/DOMPurify strips malicious tags, and the Semantic Gatekeeper rejects it as a non-coherent product idea before any heavy processing occurs.

**Scenario 4: Heavy Payload Cloud Task**

- **WHEN** the payload exceeds typical limits
- **THEN** the payload is saved to `cloud_tasks_payloads`, the worker retrieves it via `payloadDocId`, executes the atomic write batch, and deletes the payload document.
