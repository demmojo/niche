### 1. Data Model\nThe Supabase schema will be updated with the following additions and modifications:\n\n#### `products` Table\n* `id` (uuid, primary key)\n* `user_id` (uuid, foreign key to `auth.users`)\n* `name` (text)\n* `description` (text)\n* `cloudflare_account_id` (text) - *The Cloudflare account ID associated with the deployment._\n_ `cloudflare_api_token` (text, encrypted at rest) - _The user-provided Cloudflare API token with specific scopes._\n* `deployment_status` (enum: `unprovisioned`, `queued`, `building`, `deployed`, `failed`) - *Current state of the deployment pipeline._\n_ `deployed_url` (text, nullable) - _The URL of the successfully deployed application._\n* `cloudflare_site_tag` (text, nullable) - *The Web Analytics RUM JS snippet ID._\n_ `deployed_at` (timestamp, nullable) - _Timestamp of successful deployment. Used to enforce "at most once"._\n\n#### `product_features` Table\n* `id` (uuid, primary key)\n* `product_id` (uuid, foreign key to `products.id`)\n* `name` (text)\n* `status` (enum: `planned`, `in-progress`, `completed`)\n* `shipped_at` (timestamp, nullable) - *Timestamp when the feature status changed to `completed`. Crucial for AI correlation._\n\n#### `gtm_metrics_snapshots` Table (Optional for caching)\n_ `id` (uuid, primary key)\n* `product_id` (uuid, foreign key to `products.id`)\n* `timestamp` (timestamp)\n* `page_views` (int)\n* `unique_visitors` (int)\n* `conversion_rate` (float)\n\n### 2. API Contracts and Scenarios\n\n#### `POST /api/cloudflare/connect`\n**Purpose:** Validates and securely stores the user's BYOK Cloudflare API token and account ID.\n**Payload:** `{ productId: string, accountId: string, apiToken: string }`\n**Preconditions:**\n* `productId` must correspond to an existing product owned by the authenticated user.\n* `accountId` must be a valid Cloudflare account ID.\n* `apiToken` must be a valid Cloudflare API token with the required permissions (Workers Scripts, Routes, KV Storage, Web Analytics).\n**Actions:**\n1. Decrypt `apiToken`.\n2. Validate `apiToken` against the `accountId` by making a small, authorized Cloudflare API call (e.g., fetching account details).\n3. Encrypt `apiToken` for storage.\n4. Update the `products` table: `cloudflare_account_id`, `cloudflare_api_token`.\n**Returns:** `{ success: boolean, message: string }`\n**Error Conditions:**\n* 400 Bad Request if `productId`, `accountId`, or `apiToken` is missing or invalid.\n* 401 Unauthorized if token validation fails.\n* 403 Forbidden if the token lacks necessary permissions.\n\n#### `POST /api/cloudflare/deploy`\n**Purpose:** Initiates the OpenNext deployment pipeline for a given product.\n**Payload:** `{ productId: string }`\n**Preconditions:**\n* `productId` must correspond to an existing product owned by the authenticated user.\n* The `products.cloudflare_api_token` and `cloudflare_account_id` must be set.\n* `products.deployed_at` must be `NULL` (enforces "at most once" deployment).\n**Actions:**\n1. Retrieve `cloudflare_api_token` and `cloudflare_account_id` for the `productId`.\n2. **Validate Deployment Constraint**: If `products.deployed_at` is not `NULL`, reject the request with a 400 Bad Request.\n3. Update `products.deployment_status` to `queued`.\n4. **Provision Web Analytics**:\n _ Make a `POST` request to `https://api.cloudflare.com/client/v4/accounts/{account_id}/rum/site_info` using the user's token.\n _ Extract the `site_tag` from the response.\n _ Update `products.cloudflare_site_tag` with the new `site_tag`.\n5. **Enqueue Background Job**: Push a job to the background message queue containing `productId` and `cloudflare_site_tag`.\n _ The background worker will:\n _ Generate a scaffolded Next.js application codebase.\n _ Inject the `cloudflare_site_tag` into `layout.tsx` (or equivalent main layout file).\n _ Execute `npx @opennextjs/cloudflare build` to create the Cloudflare Pages compatible output.\n _ Execute `npx wrangler deploy --api-token={decryptedApiToken} --account-id={accountId} --name={projectName}` to deploy.\n _ Update `products.deployment_status` to `building`, then `deployed` or `failed`.\n _ Upon success, update `products.deployed_at` to `NOW()` and `products.deployed_url` with the deployed URL.\n**Returns:** `{ jobId: string, status: "queued" }`\n**Error Conditions:**\n* 400 Bad Request if `productId` is missing, `deployed_at` is already set, or credentials are not configured.\n* 500 Internal Server Error if Web Analytics provisioning fails or job enqueuing fails.\n\n#### `POST /api/cloudflare/graphql`\n**Purpose:** Fetches RUM traffic metrics from Cloudflare's GraphQL Analytics API.\n**Payload:** `{ productId: string, dateRange: { start: ISO8601, end: ISO8601 } }`\n**Preconditions:**\n* `productId` must correspond to an existing product owned by the authenticated user.\n* The `products.cloudflare_api_token` and `cloudflare_account_id` must be set.\n* `products.cloudflare_site_tag` must be set (indicating Web Analytics is provisioned).\n**Actions:**\n1. Retrieve `cloudflare_api_token`, `cloudflare_account_id`, and `cloudflare_site_tag` for the `productId`.\n2. Construct a GraphQL query targeting `rumPageloadEventsAdaptiveGroups` using the `site_tag` and `dateRange`.\n3. Execute the query against `https://api.cloudflare.com/client/v4/graphql` using the user's `apiToken`.\n4. Parse and aggregate the response data.\n**Returns:** `{ pageViews: number, uniqueVisitors: number, conversionRate: string, referrers: string[], dailyTimeSeries: Array<{ date: string, views: number, visitors: number }> }`\n**Error Conditions:**\n* 400 Bad Request if `productId` or `dateRange` is missing/invalid, or credentials/site tag are not configured.\n* 401 Unauthorized if the Cloudflare API token is invalid or expired.\n* 500 Internal Server Error if the GraphQL query fails.\n\n#### `POST /api/gtm/analyze`\n**Purpose:** Executes AI-Driven GTM Analysis & Attribution.\n**Payload:** `{ productId: string, dateRange: { start: ISO8601, end: ISO8601 } }`\n**Preconditions:**\n* `productId` must correspond to an existing product owned by the authenticated user.\n* RUM data must be available for the `dateRange`.\n* `product_features` must exist for the product.\n**Actions:**\n1. Fetch RUM metrics for the `productId` and `dateRange` via `POST /api/cloudflare/graphql`.\n2. Fetch `product_features` associated with `productId` that have a `shipped_at` timestamp within or relevant to the `dateRange`.\n3. Construct the Context Payload (JSON) including product details, metrics, and shipped features.\n4. Invoke the configured LLM (Claude 3.5 Sonnet / Gemini 1.5 Pro) with the System Prompt and Context Payload, enforcing the Response Schema (JSON Mode).\n5. Return the parsed LLM response.\n**Returns:** `{ summary: string, strategy: string, actionPoints: string[], featureAttribution: Array<{ featureName: string, impactAnalysis: string, confidenceScore: number }> }`\n**Error Conditions:**\n* 400 Bad Request if `productId` or `dateRange` is missing/invalid.\n\* 500 Internal Server Error if fetching metrics fails or LLM invocation fails.
