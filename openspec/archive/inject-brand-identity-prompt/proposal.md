# Proposal: Inject Brand Identity into Prompt Exporter

## Why

Currently, the Strategy-to-Code prompt exporter only extracts Jobs-To-Be-Done and Competitor Flaws. Without explicit brand guidelines, external AI code generators (like v0.dev, Bolt.new, Claude) output generic, corporate "Tarpit" UIs. To fully realize the differentiated "Blue Ocean" brand identity discovered in the Brand Positioning Wizard, we must directly inject visual and tonal guidelines into the exported prompt.

## What Changes

1. Add a pure function (`promptAssembler.ts`) to format and append the `ProjectBrandIdentity` (hex colors converted to HSL, typography, and personality) to the CO-STAR structure.
2. Introduce a semantic validation step in the Artifact Reviewer to evaluate AI-generated microcopy against the brand's Tone.
3. Add a brand enforcement toggle to the `StrategyToCodeWizard.tsx` UI.

## Capabilities

- Translates hex colors into shadcn/ui native HSL variables for reliable theming overrides.
- Automatically generates copywriting directives ensuring tone alignment.
- Protects against LLM prompt injection by securely bounding pasted code within XML tags.

## Impact

Drastically improves the baseline UI/UX quality generated by external AI tools, enforcing brand consistency, minimizing manual styling tweaks, and accelerating the Strategy-to-Code workflow.
