# Proposal

## Why
Our `CONTRIBUTING.md` specifies a Testing Trophy strategy with >80% coverage enforced, but automated check-coverage scripts and skills currently enforce a 90% threshold, causing friction.

## What Changes
The enforced coverage threshold across the repository documentation, rules, and skills will be updated to 80%.

## Capabilities
Developers can successfully verify and archive features with >= 80% code coverage instead of 90%.

## Impact
Reduced friction when verifying changes, aligning the enforcement tooling with the documented standard.
