# Proposal: NicheAI UX Strategy (Onboarding & Validation)

## Why

NicheAI's core onboarding and market validation workflow requires an academically rigorous, psychologically optimized experience. By replacing subjective "wedge metrics" with mathematically grounded frameworks and removing the "blank canvas" effect, we can significantly improve user activation rates, trust, and retention.

## What Changes

- **Evidence-Based Onboarding**: Implementation of Intent-Based Routing and Progressive Disclosure to reduce decision fatigue.
- **Optimized Time-to-First-Value (TTFV)**: Pre-population of competitor data via Exa/Apollo and UI enhancements utilizing Explainable States (The Labor Illusion).
- **Scientific Validation Flow**: Replacing arbitrary scoring with Anthony Ulwick's Jobs-To-Be-Done (JTBD) Opportunity Scoring and Quantitative Gap Analysis.
- **Actionable Outputs & Activation**: Introducing the IKEA Effect through editable validation results and a Reverse Demo Hook (PQL Gate).

## Capabilities

- Route users instantly based on a specific "Job to Be Done".
- Calculate JTBD Opportunity Score using the formula: `Importance + Math.max(Importance - Satisfaction, 0)`.
- Extract structured market deficits from negative competitor reviews.
- Stream granular AI labor updates via Server-Sent Events (SSE).
- Gate premium activation ("Generate Full Campaign") behind a high-value validation step.

## Impact

- **User Engagement**: Reduced cognitive load via Hick's Law, faster TTFV, and increased trust via transparent AI processing.
- **Conversion**: Higher paid activation through the Reverse Demo Hook and sunk-cost investment mechanisms.
